# 🏫 SchoolManagement
Performing CRUD operations on Teacher and Student lists
![school_management_logo](assets/school_management_logo.jpg)

## 💻 About program
*Sections:*
1. *Add Teacher data, insert random, extract data(all and by id), modify data, delete data*
2. *On Student data:*

- *Add random students*
- *Add students range*
- *Add student*
- *Get all students data (groped by classes)*
- *Get student by ID*
- *Search student by Name*
- *Get student on the page*
- *Get students count*
- *Change student*
- *Delete student*
